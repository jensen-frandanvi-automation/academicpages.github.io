## Abstract

We present SynLogic, a framework for synthesizing verifiable reasoning data at scale to improve logical reasoning in large language models. Our approach demonstrates that synthetic data with verifiable reasoning steps can significantly enhance model performance on logical reasoning benchmarks while maintaining factuality and interpretability.

## Key Contributions

- A scalable framework for generating verifiable logical reasoning data
- Comprehensive evaluation across multiple reasoning benchmarks
- Analysis of how synthetic reasoning data affects model interpretability
- Demonstration of improved truthfulness in reasoning outputs
